# Christmas Village 🎄

หมู่บ้านคริสต์มาส: นับถอยหลัง ขอพรซานต้า การ์ดสุ่มจี้ และลูกแก้วหิมะ
Languages: ไทย / English / 中文 / Español

Single-file web app (`index.html`), no build step, no dependencies
(only Google Fonts "Mali", with system-font fallback).

## Run locally
Open `index.html` in a browser.

## Deploy
**Vercel:** Add New → Project → import this repo → Framework Preset: *Other*,
leave Build Command and Output Directory empty → Deploy.

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.
